# A totally-unbiased coinflip.
## What is the point of this?
A small scale idea to introduce myself to react via vite. Also an excuse to learn vim motions.
## Future Ideas
I don't really have many aspirations for an idea this small scale. I do think it would be a cool idea to introduce some kind of animation to mimic a coinflip.
The way I would invision it is a binary scale, with 3 values appearing side by side like this : 001 or 110 or 000.
This would have to get implemented so it *rolls* a bit like a roulette wheel of sorts. For example:
- First roll : 001
- Second roll : 011
- Third roll : 110
- Fourth roll : 100

The general idea is that the state is pseudo-preserved, mimicking the values scrolling.
